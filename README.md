# Shaman film

Code-drawn pixel film engine. Python 3 + Pillow + NumPy + PyYAML, FFmpeg on PATH.

    pip install pillow numpy pyyaml
    python render.py episodes/ep00_test           # full test reel -> out/ep00_test/ep00_test.mp4
    python render.py episodes/ep00_test --keys    # key frames + contact sheet only

See CLAUDE.md for the format rules and the review loop.
